# 计算机系统

深入了解计算机系统的底层原理，包括计算机组成、系统架构等核心概念。

## 📚 文档列表

### 计算机组成原理

- [计算机组成](./计算机组成.md) - 计算机硬件组成与工作原理：CPU、内存、存储、I/O系统

## 🎯 核心主题

### 硬件组成
- **中央处理器(CPU)**: 指令执行与运算控制
- **存储系统**: 内存层次结构与缓存机制
- **输入输出**: I/O设备与接口控制
- **总线系统**: 数据传输与系统互连

### 系统原理
- **指令系统**: 指令格式与寻址方式
- **控制器设计**: 硬布线与微程序控制
- **流水线技术**: 指令流水线与性能优化
- **并行处理**: 多核与并行计算架构

### 存储层次
- **高速缓存**: Cache原理与性能分析
- **主存储器**: DRAM技术与内存管理
- **辅助存储**: 磁盘存储与固态硬盘
- **虚拟存储**: 分页与分段机制

## 🚀 学习路径

1. **基础篇**: 计算机组成原理 → 指令系统
2. **进阶篇**: 存储系统 → 输入输出系统  
3. **高级篇**: 流水线技术 → 并行处理

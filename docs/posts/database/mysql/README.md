# MySQL 数据库技术

深入探索MySQL数据库的核心技术，包括存储引擎、锁机制、事务原理等。

## 📚 文档列表

### MySQL 核心技术

## 🎯 核心主题

### 存储引擎
- **InnoDB**: 事务型存储引擎，支持ACID
- **MyISAM**: 非事务型存储引擎，读写分离优化
- 存储引擎对比与选择

### 锁机制
- **表级锁**: MyISAM默认锁粒度
- **行级锁**: InnoDB精细化锁控制
- **意向锁**: 多粒度锁并存机制
- **死锁**: 产生原因与避免策略

### 事务与MVCC
- **ACID属性**: 原子性、一致性、隔离性、持久性
- **隔离级别**: READ UNCOMMITTED到SERIALIZABLE
- **MVCC**: 多版本并发控制机制

### 性能优化
- **索引优化**: B+树索引、复合索引、覆盖索引
- **查询优化**: 执行计划分析、慢查询优化
- **配置调优**: 参数优化、缓存配置

## 🚀 学习路径

1. **基础篇**: 存储引擎 → 锁机制
2. **进阶篇**: 事务与MVCC → 索引原理
3. **高级篇**: 性能调优 → 集群架构

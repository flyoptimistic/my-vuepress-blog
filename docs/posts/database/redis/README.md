# Redis 技术文档

Redis（Remote Dictionary Server）是一个开源的内存数据结构存储，用作数据库、缓存和消息代理。

## 📚 文档列表

### Redis 核心技术

- [Bloom Filter](./Bloom\ Filter.md) - 布隆过滤器原理与应用：概率型数据结构，解决缓存穿透问题

## 🎯 核心主题

### 数据结构
- **String**: 字符串类型，支持二进制安全
- **Hash**: 哈希表，适合存储对象
- **List**: 链表结构，支持双端操作
- **Set**: 无序集合，支持集合运算
- **ZSet**: 有序集合，支持范围查询

### 高级特性
- **布隆过滤器**: 概率型数据结构，内存高效
- **HyperLogLog**: 基数估算算法
- **BitMap**: 位图操作
- **Stream**: 消息流数据类型

### 持久化机制
- **RDB**: 快照持久化
- **AOF**: 追加文件持久化
- **混合持久化**: RDB+AOF结合

### 集群架构
- **主从复制**: 数据冗余与读写分离
- **哨兵模式**: 高可用解决方案
- **集群模式**: 数据分片与横向扩展

## 🚀 应用场景

### 缓存应用
- **数据缓存**: 减少数据库压力
- **会话缓存**: 分布式会话存储
- **页面缓存**: 静态资源缓存

### 防护机制
- **缓存穿透**: 布隆过滤器预防
- **缓存击穿**: 热点数据保护
- **缓存雪崩**: 过期时间分散

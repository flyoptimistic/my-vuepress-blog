# 成长记录

## 栏目定位

这里记录技术学习之外的过程信息：阶段目标、实践过程、问题复盘、读书思考和长期成长轨迹。它和技术专题互相补充，帮助我回看自己为什么学习、如何学习、学到了什么。

## 适合读者

- 想了解这个博客更新脉络的读者。
- 正在学习 Java 后端、希望参考阶段规划的人。
- 对个人知识管理、复盘和长期成长感兴趣的人。

## 内容范围

- 每周学习记录和问题整理。
- 月度、季度、年度复盘。
- 项目实践和博客维护复盘。
- 技术之外的读书、思考和行动计划。

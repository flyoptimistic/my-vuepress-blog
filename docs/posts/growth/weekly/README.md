# 成长周记

## 栏目定位

成长周记用于记录每周的学习状态和实践过程。它不追求每篇都很完整，而是保留阶段性的真实问题、行动和反馈。

## 适合读者

- 希望了解博客近期更新和学习重点的读者。
- 希望参考 Java 后端学习节奏的人。
- 需要建立复盘习惯的学习者。

## 内容范围

- 本周学习主题和关键词。
- 实际完成的文章、代码、项目或阅读。
- 遇到的问题和排查过程。
- 本周收获、反思和下周计划。

## 推荐阅读顺序

按时间倒序阅读即可。后续新增正式周记后，会在这里维护索引。

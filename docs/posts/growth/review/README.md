# 阶段复盘

## 栏目定位

阶段复盘用于整理较长周期的学习和实践结果。相比周记，这里更关注目标是否达成、哪些方法有效、哪些问题需要调整。

## 适合读者

- 希望查看完整阶段总结的读者。
- 正在做技术成长规划的人。
- 想了解博客内容建设路线的人。

## 内容范围

- 月度、季度和年度复盘。
- 项目实践复盘。
- 技术专题学习复盘。
- 博客内容治理和维护复盘。

## 推荐阅读顺序

1. 先看年度或季度复盘，了解阶段主线。
2. 再看项目复盘，了解具体实践。
3. 最后回到周记查看过程细节。

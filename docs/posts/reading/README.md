# 读书与思考

## 栏目定位

这里记录读书笔记、优秀文章摘录和读后思考。读书不是为了摘抄结论，而是为了把输入转化为可执行的理解、问题和行动。

## 适合读者

- 想了解我近期输入来源的读者。
- 想参考技术书阅读路线的学习者。
- 对学习方法、个人成长和工程思维感兴趣的人。

## 内容范围

- Java、JVM、并发、数据库等技术书读书笔记。
- 工程实践、架构设计、职业成长相关书籍。
- 优秀文章、课程和公开资料的摘录与理解。
- 读后行动计划和阶段复盘。

## 推荐阅读顺序

1. 技术书笔记：补充技术专题的系统输入。
2. 工程实践笔记：连接项目经验和方法论。
3. 成长类笔记：沉淀长期学习和复盘方法。

# Java 后端成长路线

## 栏目定位

这里是 Java 后端学习的总入口，围绕语言基础、JVM、并发编程、Spring 生态和工程实践，沉淀从知识点到问题解决的成长路线。

## 适合读者

- 正在系统学习 Java 后端的读者。
- 希望按专题复习 JVM、并发和 Spring 的开发者。
- 关注技术成长路径和长期复盘的人。

## 内容范围

- Java 基础语法、集合、IO、异常、泛型和反射。
- JVM 类加载、内存模型、对象分配和垃圾回收。
- Java 并发编程、JMM、锁、线程池和并发容器。
- Spring Framework、Spring Boot 和后端工程实践。

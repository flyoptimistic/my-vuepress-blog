## 我是谁

我是北木南，一个持续学习 Java 后端、工程实践和 AI 辅助开发的技术学习者。这个博客是我的长期记录空间，用来沉淀技术理解、项目实践、阶段复盘和读书思考。

> 纸上得来终觉浅，绝知此事要躬行。

## 这个博客记录什么

这里不是单纯的资料收集站，而是我从问题、实践、复盘到再整理的成长轨迹。技术文章会尽量写清楚背景、结论、适用范围和验证过程；成长记录会保留阶段状态、踩坑过程和下一步计划。

主要内容包括：

- Java 后端学习路线和工程实践
- JVM、并发编程、数据库等技术专题
- 博客维护、工具链和开发记录
- AI 工具使用、提示词和效率实践
- 周记、阶段复盘、读书笔记和个人思考

## 当前关注方向

- Java 后端基础能力：集合、IO、并发、JVM、Spring 生态。
- 高并发与性能：线程模型、锁、JMM、GC、数据库索引和缓存策略。
- 工程实践：脚本自动化、持续部署、博客内容治理和问题复盘。
- AI 辅助开发：Claude、Gemini、Codex 等工具在学习和开发中的实践方法。

## 我的技术主线

我的技术主线会围绕“后端工程能力”长期展开：

- **Java 基础**：语言特性、集合框架、异常、泛型、反射和 IO。
- **JVM 与并发**：类加载、内存模型、对象分配、GC、JMM、锁和线程池。
- **Spring 生态**：IoC、AOP、事务、Web MVC、Spring Boot 自动配置。
- **数据库与缓存**：MySQL 索引、事务、锁、MVCC、Redis 数据结构和缓存一致性。
- **工程化实践**：构建部署、脚本工具、问题定位、文档治理和持续改进。

## 写作原则

- **先实践再总结**：尽量让结论来自代码、实验或真实问题。
- **写清适用范围**：涉及版本差异时标注环境、版本和验证时间。
- **保留问题过程**：不仅记录答案，也记录误区、排查路径和复盘。
- **长期持续修订**：旧文章会随着理解加深持续补充和修正。
- **技术与成长并重**：技术文章沉淀能力，成长记录保留轨迹。
